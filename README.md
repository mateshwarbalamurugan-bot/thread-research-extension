# THREAD — Research Knowledge Graph

THREAD is a Chrome extension designed to help users collect, organize, and connect useful information from websites for research.

## Planned Features

- Save selected text using the browser's right-click menu.
- Store the text along with its original source URL and title.
- Organize saved findings into separate research projects.
- Display saved findings as nodes on a graph canvas.
- Connect findings using relationships such as Supports, Contradicts, and Related To.
